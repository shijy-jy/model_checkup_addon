# Model Checkup

## 安装

从 [Releases](../../releases) 下载 `model_checkup_addon.zip`，在 `Edit` → `Preferences` → `Get Extensions` → `Install from Disk...` 中选择安装。

## 使用

3D 视图按 `N` 打开侧栏，切到 Checkup 标签页，选择范围（整个场景或选中对象）后运行检查。

## 检查项

| 类别 | 检查项 | 级别 | 说明 |
| --- | --- | --- | --- |
| 网格 | 空网格 | 错误 | 面数为 0 |
| 网格 | 空壳网格 | 警告 | 全部面面积为 0；命中后终止检查 |
| 网格 | 松散顶点 | 提示 | 顶点不属于任何边 |
| 网格 | 非流形边 | 提示 | 边被 3 个以上面共享 |
| 网格 | N 边形 | 提示 | 面顶点数大于 4 |
| 网格 | 零面积面 | 提示 | 面积小于 1e-12 |
| 网格 | 面数偏高 | 提示 | 三角面数超过 `tri_warn` |
| UV | 缺少 UV | 错误 | 有贴图但对象没有 UV 层 |
| UV | UV 越界 | 提示 | UV 点超出 0–1 的比例 |
| UV | UV 重叠 | 提示 | 重叠面积占比超过 `uv_overlap_warn` |
| 材质 | 贴图失效 | 错误 | 原路径与工程目录内均未找到 |
| 材质 | 面未指定材质 | 警告 | 材质索引越界或指向空槽 |
| 材质 | 贴图需重链 | 提示 | 已按文件名在工程目录找到 |
| 材质 | 贴图未打包 | 提示 | 未打包进 `.blend` |
| 材质 | MMD 着色器 | 提示 | 使用 MMD 节点组，需替换为 PBR |
| 材质 | 材质数量偏多 | 提示 | 材质槽数超过 `material_warn` |
| 变换 | 负缩放 | 错误 | 绕序与法线方向反转 |
| 变换 | 变换未应用 | 警告 | 根级对象残留缩放或旋转 |
| 变换 | 变换随层级保留 | 提示 | 对象有父级，变换随层级导入 |
| 法线 | 绕序不一致 | 错误 | 相邻面在同一条边上方向相同 |
| 法线 | 法线整体朝内 | 错误 | 封闭网格有符号体积小于 0 |
| 法线 | 法线可能朝内 | 警告 | 开放网格朝外占比低于 35% |
| 蒙皮 | 未指派权重 | 错误 | 顶点没有任何骨骼权重 |
| 蒙皮 | 影响骨骼超过 4 根 | 警告 | 超出部分被 Unity 丢弃 |
| 蒙皮 | 权重和不为 1 | 警告 | 容差 1e-4 |
| 蒙皮 | 非骨骼顶点组 | 提示 | 顶点引用了名称不在骨骼集合中的组 |
| 尺寸 | 尺寸超出常规范围 | 警告 | 最长边大于 1000 m 或小于 1 mm |

错误为导入后不可用；警告为可导入但会出现问题；提示为需人工确认或正常现象。任一错误判为不可用，无错误但有警告判为存在风险。阈值见 `model_checkup/constants.py`。
